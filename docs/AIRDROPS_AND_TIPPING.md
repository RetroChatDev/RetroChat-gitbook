# Tipping & Airdrops

Send SOL or supported SPL tokens directly to other members, and run token airdrops as a community owner.

## Tips

### Send a tip

1. Open a user's profile, a message they sent, or a post they made.
2. Tap the **Tip** button.
3. Choose a token (SOL by default) and amount.
4. Approve the transaction with your in-app wallet biometric/passphrase prompt or with Phantom.

Tips are on-chain transfers. They settle in seconds and appear in both parties' [wallet history](WALLET_GUIDE.md).

### Receive tips

Any user with a wallet linked to RetroChat can receive tips. You'll get an in-app notification and (if enabled) a push notification when a tip lands.

### Tip Leaderboard

The **Tip Leaderboard** on user profiles shows global rankings for:

- Top tippers (most SOL sent).
- Top recipients (most SOL received).

## Airdrops

Community owners can run airdrops to reward members.

### Create an airdrop

1. Open a community you own.
2. Choose **Manage airdrops** (community actions menu), which opens `/communities/<slug>/airdrops`.
3. Choose a token, total amount, and recipient list (paste addresses, upload CSV, or select community members).
4. Review the estimated cost.
5. Approve the transaction.

Recipients receive an in-app notification when their tokens land.

### Best practices

- Announce the airdrop in the target community before running it.
- Start with a small test batch when using a new recipient list.
- Airdrops are on-chain and irreversible — double-check the recipient list.

## z500 / $ANSEM holder airdrops

If your linked wallet holds **$ANSEM** (typically 100+ tokens for snapshot eligibility; the live threshold is shown in the wallet card), RetroChat can surface:

- Eligibility and an **estimated** z500 airdrop exposure on the Wallet and Token Studio portfolio cards (equal-share estimate vs recent distributions — not a guaranteed payout).
- An in-app **Unclaimed z500 airdrop** reminder when ansem.io has open claims.
- **Claim on ansem.io** links. Claims are processed on ansem.io, not inside RetroChat.

These are third-party distributions. Verify the $ANSEM mint before buying or claiming, and treat Gold/Diamond/z500 rank as attention, not an audit.

## Supported wallets

- **RetroChat in-app wallet** (biometric or passphrase approval).
- **Phantom** on desktop, mobile, and inside the Phantom in-app browser.
