# Learn Center

The Learn Center is RetroChat's built-in help library — searchable articles on wallets, meme-coin basics, safety, Token Studio, and using the app.

## Open Learn

Open **Learn** from the dashboard (**Why Meme?** shortcut) or the main menu. You must be signed in.

Every visit shows a crypto risk disclaimer. Articles are educational, not financial advice.

## Browse

Articles are grouped by category, for example:

- Getting started and platform basics
- Wallets and transactions
- Communities and live
- Token Studio and DeFi concepts (including **The 5% creator fee lock**)
- Tools and launchpads (including **ansem.io and the z500 index**)
- Safety and scam awareness
- Glossary-style explainers

Expand a category accordion to see titles and short summaries. Official RetroChat articles show a verified / reviewed badge with a review date when available.

## Search

Use the search bar at the top to filter all articles by keyword. Results update as you type.

## Read an article

Each article opens as a mobile-friendly page with headings, images, and source links where claims are backed by external references. Related articles may appear at the end.

## Contribute

Members can submit new articles or suggested edits from **Learn → Contribute**.

- Include source URLs for factual claims.
- Track status under **My submissions** (pending, needs changes, verified, or rejected).
- Only verified contributions are published into the public article set.

## Suggest an edit or flag inaccurate content

On an article page:

- **Suggest edit** — propose a correction for review.
- **Flag this article** — report outdated or wrong content. The team is notified and will update or remove it.

## How this relates to these docs

The Markdown guides in this documentation set cover **how to use** each RetroChat surface. Learn Center articles go deeper on **concepts** (bonding curves, wallets, scams) and may also include short RetroChat how-tos. Prefer Learn for education and these guides for product steps; both are updated when major features ship.
